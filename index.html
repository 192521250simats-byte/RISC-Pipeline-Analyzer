01 / PROBLEM STATEMENT

Processor Design Challenge

⚡

RISC Pipeline & Cache Performance Problem

A processor design team is developing a 5-stage RISC pipeline consisting of Instruction Fetch (IF), Instruction Decode (ID), Execute (EX), Memory Access (MEM), and Write Back (WB).

The processor must correctly identify and handle Read After Write (RAW) dependencies between instructions. The design must analyze dependent instructions, including a load-use hazard such as LOAD R1, 0(R2) followed by ADD R4, R1, R5.

A Hazard Detection Unit must identify dependencies by comparing source and destination registers. EX/MEM-to-EX and MEM/WB-to-EX forwarding paths are required to reduce unnecessary stalls.

The system also integrates an L1 cache into the MEM stage to study cache hits, cache misses, CPI, pipeline efficiency, speedup and throughput.
